Common Symbols & Conditions

Quick reference guide for standard mathematical symbols used across all entries.

Symbol Meaning / Usage Example
$\in$ Element of a set $x \in \mathbb{R}$ ($x$ is a real number)
$\forall$ For all / For every $\forall x > 0$
$\therefore$ Therefore $\therefore x = 5$
$\equiv$ Identically equal to / Congruent $\triangle ABC \equiv \triangle DEF$
$\sum$ Summation $\sum_{i=1}^{n} x_i = x_1 + x_2 + \dots + x_n$
$\int$ Integration (Definite or Indefinite) $\int x^2 dx = \frac{x^3}{3} + C$
$\partial$ Partial derivative $\frac{\partial f}{\partial x}$
$|x|$ Absolute value or Modulus $|-5| = 5$
