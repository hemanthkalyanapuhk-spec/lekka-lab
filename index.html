📄 Lekka Lab Daily Practice Sheet: Number Sense & Place Value

Student Name: _______________________ Date: ____________ Max Score: 12
1. Write the number name for 48: ________________________
2. Fill in the blanks: 76 = ______ Tens + ______ Ones.
3. What number comes strictly between 89 and 91? Answer: ______
4. Insert > or <:   64 [   ] 46   and   108 [   ] 180.
5. Add with carrying:   47 + 38 = _________
6. Money Problem: If a pencil costs ₹5 and an eraser costs ₹3, find the total cost: ₹_________
Answer Key:
1. Forty-eight.
2. 7 Tens + 6 Ones.
3. 90.
4. Correct comparison symbols.
5. 85.
6. ₹8.
